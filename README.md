# 🏆 Smart India Hackathon 2026 — Internal Round

This project was developed for the **Smart India Hackathon (SIH) 2026 Internal Round**.

The project focuses on building an **AI-Based Intelligent Video Analytics Platform for Border Surveillance using Existing CCTV Infrastructure**.

The objective is to demonstrate how existing CCTV cameras can be enhanced with AI-powered analytics to identify potentially suspicious activity and security breaches without requiring additional surveillance hardware.

### Key Demonstration Areas

* Real-time person and vehicle detection
* Object tracking with persistent IDs
* Restricted-zone / virtual fence monitoring
* Intrusion detection
* Loitering detection
* Suspicious rapid-movement detection
* Face detection
* Number-plate localisation
* Night-time / low-light enhancement
* Real-time security event logging
* Web-based surveillance dashboard
